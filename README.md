# Escape Lab: Artbildung

Digitales Escape-Spiel für den Biologieunterricht in der Sek II (ca. 30 Minuten), gedacht als wiederholender Einstieg in die Evolution.

**Inhalte:** Artbegriffe (biologisch, populationsgenetisch), allopatrische und sympatrische Artbildung, prä- und postzygotische Isolationsmechanismen, Voraussetzungen der adaptiven Radiation.

**Ablauf:** Gruppen zu 3–4 Personen lösen sechs Stationen auf einem Gerät. Das Spiel startet erst mit dem Startpasswort der Lehrkraft.

Das Spiel läuft komplett im Browser. Es werden keine Daten an einen Server gesendet, der Fortschritt wird nur lokal im Browser gespeichert.

Die Schrift wird von Google Fonts geladen. Ohne Internet nutzt der Browser eine Standardschrift.
